# E1／E2 真实模型评估准备

`tasks.json` 是待冻结的任务草案；`scoring.md` 是独立评分材料。使用下面的命令在新目录生成单个任务；脚本不复制评分材料或其他任务。E1-03 包含实际代码和测试，E2 三题包含对应固定材料和研究记录；受试项目应作为独立项目打开并按宿主的正常流程关联会话。

```bash
PYTHONPATH=src python3 scripts/e1e2_evaluation_fixture.py \
  --task E2-01-stale --destination /private/tmp/e1e2-eval-run-01
```

执行前固定模型 provider／model／variant、可用工具、总预算和每任务额度，并按种子配对运行 B（完整读取）、C（仅探索提示）、D（证据结项）和 E（完整 E1／E2）；原项目实际策略作为单独 A 组。每次创建新的任务目录。记录全部运行，包括失败和中断；用量缺失记 unknown，不记零。先独立评分再揭盲，分别报告工程正确性、质量与成本，样本不足只报告描述性结果。组别分配和模型运行尚需在确定额度后执行。

当前没有运行真实模型、没有选择付费服务或额度，也没有质量提升结果。已有的脚本化宿主测试只验证接口、事务与恢复行为。

E1 选择与资源中断任务目前主要提供文本输入，还没有能对外隐藏真值的可执行测量服务或配对运行器；正式比较之前仍需补齐这些设施并冻结题目。现有夹具足以检查任务隔离和 E2 的预置账本状态，不能代替真实模型试验。
