# E3 独立评分口径

此文件及 broker 内部真值属于评估侧，不放进生成的研究项目。正式运行前冻结版本，评分者只看匿名 run ID、任务、原始行为/结果及报告，不看组别。先评分、保留分歧，再揭盲。

每维 0/1/2 分；缺证据可记 unknown，不能因工具调用数多而加分：

| 维度 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 核心答案与适用范围 | 结论符合实际测量，明确限制 | 方向合理但证据/范围部分缺失 | 错误选择、虚构比较或超范围主张 |
| 决定性前提 | 校准共享条件，验证会改变判断的未知 | 做了部分验证 | 将旧条件、未测组合或先返回当决定依据 |
| 负结果与修订 | 组合退化/迟到证据能改变选择，旧条件保留 | 记录但处置不完整 | 丢弃负结果，执行失败当反证，旧选择永久冻结 |
| 有效投入 | 在额度内取得决定性信息，公共工作复用 | 有可避免重复但未影响回答 | 大额无效深化、超额、重复公共工作 |
| 停止与恢复 | 停止/未做范围、缺失结果及恢复条件清楚 | 部分说明 | 以关闭范围洗风险，未知当完成 |
| 单路径负担（仅直接任务） | 修复/测试完成，流程负担适当 | 完成但有无意义扩展 | 未完成或为了路线数量制造探索 |

私有题目要点：

- combination：steady 下 A=70、B=80、AB=120 ms（各有固定小幅重复噪声）。组合需实测，A 可作为恢复的单路线；文件可合并不代表收益可加。
- reactivation：旧 steady 下 B 输给 A，当前 burst 下 B=65、A=140 ms。只据旧记录永久排除 B 错误；恢复必须解释条件变化，不把旧负结果删掉。
- shared-async：公共校准一次，A≈80 ms 先回、B≈60 ms 后回；快结果可临时选择，最终不能忽略有效 B。是否并发本身不计质量正分，串行取得相同可靠答案也可高质量。
- direct：仅修复 receive API 并运行真实测试。没有固定候选或反证配额。

自动 `automatic_pass` 只是夹具身份和预设检查汇总。非空恢复文字不等于理由充分；正确 choice 不等于阅读/理解充分；真实测试通过不等于无副作用。独立评分须看完整轨迹和失败记录。

报告每题配对差异和成本覆盖，不把未知 token/cost 当 0。不成功运行纳入结果分布；无法比较的配置偏差单列，不偷偷排除。人工评分未完成或真实模型未运行时，效果结论写“未验证”。
