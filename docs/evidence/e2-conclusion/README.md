# E2 工程验证

E2 使用显式采用的 `evidence-v1`；默认仍保留旧结项契约。固定版本读取、结项草案、审阅覆盖、发布的报告与证据附录，以及本次模型请求中实际收到的完整草案页，共同参与结项检查。

隔离测试覆盖核心依据缺失、自引和同内容别名、修订后的陈旧草案、未处置挑战、非核心缺口、跨代审阅显式复用、重新打开的审阅、盲评实际分配的输入、节点执行观测、原始文件损坏及分页回执。类型化审阅保留真实身份与限制；未知身份不推定为独立。当前可归属的可执行工具观测限于 `bash`、`shell`、`python` 和 `terminal`；其他来源未观察到执行时保持未知。

证据正文按需选择 UTF-8 固定文件，快照有总容量限制；未纳入或无法读取的正文会保留为限制。附录是同一草案生成并冻结的可读文件。相关功能和迁移的整体验证见 [E1 工程验证](../e1-exploration/README.md)。

上述结果证明受控场景下的工程行为，不证明模型理解材料或研究结论为真；真实模型配对效果和用户统一验收尚未完成。
