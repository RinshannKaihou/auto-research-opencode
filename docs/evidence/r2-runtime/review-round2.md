| 问题 | 处理与回归 |
|---|---|
| 后端源码扫描无界、成功重放仍扫描 | Python 完全移除文件遍历；宿主只启动一个 worker，增量缓存最近一个工作区。500ms 共享等待、10,000 目录项、2,000 源文件、16MiB 新读取字节限制；环境／site-packages／不可变 inputs 跳过。忙碌或超限不排队、不返回部分摘要。后端重放首先返回原结果，测试将 Path.open 设为禁止仍可预留／结束／重放 |

| Legacy 显示最旧的四条挑战 | 当前 generation 优先、同代最新事件优先。跨代六条挑战夹具验证最新摘要和完整历史索引同时保留 |

宿主探测摘要与 cwd／node／attempt／generation 及算法绑定，前后归属指纹不相同不得比较；读取失败、未知摘要、旧算法和新工作段均不刷新 idle。只有完整宿主摘要表示开发活动，不提供科学正确性、来源或文件完整性的证明。元数据缓存只是减轻探测成本，不能代替证据验证；硬科研预算仍独立执行。

## 保留边界

持续改动文件可能持续被识别为开发活动；idle 不承担科学价值评分，不加语义猜测过滤器。有限轮次／时限／费用阈值另行配置和执行。显式 revise 与 challenge disposition 保持两步，便利接口及独立科学审阅属于后续工作；没有自动结案或静默清除风险。

上述是确定性功能与资源边界验证，未测量真实大仓库的普遍收益、真实模型成本或科研质量，也不标为 CI 结果。
